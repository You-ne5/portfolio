# Younes Mohammedi — Portfolio

Personal portfolio built with Next.js 16, Tailwind CSS v4, and TypeScript. It's a single static page plus Markdown project detail pages, deployed on Vercel.

All content lives in `src/content/`. **See [PORTFOLIO_GUIDE.md](./PORTFOLIO_GUIDE.md)** for how to edit text, projects, skills, images, icons, section visibility and theme colors.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build (also validates content)
npm run lint
```
