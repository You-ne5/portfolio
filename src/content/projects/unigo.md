## Overview

Unigo is a production cross-platform carpooling application built for students. I worked on it as a Flutter developer at the startup from September 2025 to February 2026.

## What I built

- Firebase Auth, Firestore, and Storage integration
- Bloc state management architecture and the core user-facing flows
- Real-time route matching between drivers and passengers

## Security

Implemented the following security measures:

1. Code obfuscation on release builds
2. Firebase security rules scoped per user
3. Firebase App Check to block unauthorized clients
